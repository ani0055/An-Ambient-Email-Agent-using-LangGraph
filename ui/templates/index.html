🧬 LangGraph StateGraph Architecture

This Ambient Agent uses a stateful cyclical LangGraph workflow. When an email is detected, state flows sequentially through each node with a memory-informed checkpoint before external side-effects:

🧠
1. load_memory_node
Queries SQLite database for sender relationship, past corrections, and user preferences.
🚦
2. triage_node
Categorizes email into [ignore, notify_human, respond] based on context and urgency.
🤖
3. react_agent_node
Invokes tools (search calendar, check availability) and drafts the response payload.
🛡️
4. hitl_checkpoint (Human In The Loop)
Pauses graph execution. Emits WebSocket approval event to this UI dashboard.
🚀
5. execute_action_node
On approval, dispatches Gmail API email reply or Google Calendar event creation.
💾
6. update_memory_node
Extracts diff patterns from human feedback to reinforce preferences and update weights.
